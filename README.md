# ZhihuUI++ (知乎UI++)

ZhihuUI++ 是一款使用 Vue 3 + Vite 构建的现代化知乎浏览器扩展。它通过接管知乎底层推荐数据并重新渲染 UI，为您带来更清爽、更高效的阅读体验。

## ✨ 主要功能

- **🎨 页面重塑**：全局接管并重新渲染知乎页面，采用现代化、简洁的 UI 设计。
- **🛍️ 隐藏盐选**：一键隐藏首页信息流中的知乎盐选推广内容，还你纯净阅读。
- **🚫 屏蔽词过滤**：自动隐藏包含特定屏蔽词的推荐内容，定制专属内容流。
- **⚙️ 快捷设置面板**：提供精美的全局和首页设置面板，所有功能即时开关，配置自动同步保存。

## 🚀 本地开发与构建

本项目使用 [Vite](https://vitejs.dev/) 和 [@crxjs/vite-plugin](https://crxjs.dev/vite-plugin) 进行扩展程序的开发和打包。

### 1. 安装依赖
```bash
npm install
# 或使用 pnpm install / yarn install
```

### 2. 开发环境 (支持热更新)
```bash
npm run dev
```
运行后，在浏览器的扩展管理页面（如 `chrome://extensions/`）开启**开发者模式**，点击**加载已解压的扩展程序**，选择项目生成的 `dist` 文件夹即可。

### 3. 正式发布构建
```bash
npm run build
```
执行完毕后，`dist` 文件夹内即为经过压缩与优化后的正式版文件。您可以直接加载此文件夹作为离线版本，或将其中的所有文件打包为 `.zip` 上传至各大浏览器的扩展商店进行发布。
